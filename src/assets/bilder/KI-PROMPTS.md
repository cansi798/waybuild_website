# KI-Prompts für Waybuild-Bilder

Fertige Prompts für Bildgeneratoren (Midjourney, ChatGPT/DALL·E, Adobe Firefly, Ideogram …) –
abgestimmt auf das CI: **Papier `#F7F5F0`, Nachtblau `#0E1A2B`, Signal-Orange `#FF5A1F`**, warm, ruhig, hochwertig.

> **Wichtig:** Keine KI-Bilder von „Kunden“, „Team-Mitgliedern“ oder „Referenzprojekten“, die es nicht gibt –
> das wäre Täuschung. KI-Bilder eignen sich für **Stimmung, Illustration und Hintergründe**. Für Team und
> Referenzen immer echte Fotos/Screenshots verwenden.

**Basis-Stil (an jeden Prompt anhängen):**

```
editorial photography style, soft natural window light, warm off-white paper tones (#F7F5F0),
deep navy accents (#0E1A2B), a single signal-orange accent (#FF5A1F), calm composition,
generous negative space, shallow depth of field, no text, no logos, no watermark
```

---

## 1. Branchen-Stimmungsbilder → `allgemein/branche-*.jpg`

Format 4:3 · z. B. für künftige Branchen-Seiten („Website für Handwerker“ – gut für SEO)

```
close-up of a craftsman's hands holding a smartphone showing a clean modern website,
workshop background softly blurred, wood and tools, [Basis-Stil]
```
```
friendly dentist's reception desk with a tablet showing a modern website, bright clinic,
plants, [Basis-Stil]
```
```
small café counter, owner checking online reservations on a laptop, morning light,
ceramic cups, [Basis-Stil]
```

## 2. Konzept „Unikat statt Baukasten“ → `allgemein/unikat.jpg`

Format 16:9 · Hintergrund für Abschnitt „Warum kein WordPress?“

```
a single hand-crafted orange ceramic tile standing out among rows of identical grey
mass-produced tiles, top-down view, minimal, [Basis-Stil]
```

## 3. Konzept „Sorgenfrei betreut“ → `allgemein/sorgenfrei.jpg`

Format 4:3

```
tidy modern desk at dusk, laptop closed, a cup of coffee, small orange notebook,
feeling of calm and everything taken care of, [Basis-Stil]
```

## 4. Geschwindigkeit / Performance → `allgemein/schnell.jpg`

Format 16:9 · abstrakt

```
abstract long-exposure light trails in signal orange across a deep navy background,
sense of speed and precision, minimal, no text
```

## 5. Social-Media-Beiträge (Instagram/LinkedIn)

Format 1:1 · Text später im Design-Tool ergänzen

```
flat lay of a smartphone and laptop on off-white paper, both screens showing a clean
website with navy and orange accents, pencil and blueprint sketch beside them,
[Basis-Stil]
```

---

## Für echte Fotos (Fotograf/Smartphone)

- **Gründer-Foto (`team/gruender.jpg`)**: Oberkörper, Blick in die Kamera, freundlich; heller, ruhiger Hintergrund
  (Wand in Off-White oder Büro); Fensterlicht von der Seite; dunkle Kleidung (Nachtblau passt ideal).
- **Referenz-Screenshots (`referenzen/…`)**: Kunden-Website im Browser-Fenster, Desktop 1600 × 1200 px,
  alternativ Handy-Mockup. Nur mit Freigabe des Kunden.
