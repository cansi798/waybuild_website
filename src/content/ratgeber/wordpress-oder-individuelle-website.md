## Warum so viele Websites auf WordPress laufen

WordPress ist kostenlos, weit verbreitet und hat für fast alles ein Plugin. Das macht es beliebt, ist aber auch der Haken: Jede Funktion ist ein weiteres Plugin, das aktuell gehalten werden muss.

## Der Vergleich

| | WordPress | Individuell entwickelt |
|---|---|---|
| Ladezeit | abhängig von Theme und Plugins, oft mehrere Sekunden | meist unter 1 Sekunde |
| Sicherheit | Plugins sind das häufigste Einfallstor | keine Datenbank, keine Plugins |
| Wartung | regelmäßige Updates nötig | praktisch wartungsfrei |
| Design | oft gekauftes Theme | Unikat nach Ihren Wünschen |
| Selbst pflegen | sehr einfach | über den Anbieter |

Laut dem Sicherheitsbericht von [Patchstack (2026)](https://patchstack.com/whitepaper/state-of-wordpress-security-in-2026/) wurden 2025 über 11.000 neue Sicherheitslücken im WordPress-Umfeld gemeldet. **91 % davon steckten in Plugins**, der Rest in Themes.

## Warum die Ladezeit zählt

Google bewertet die Geschwindigkeit einer Seite mit (Core Web Vitals). Außerdem springen Besucher ab, wenn eine Seite auf dem Handy zu lange lädt. Eine schlanke, individuell entwickelte Website ist hier im Vorteil.

## Wann WordPress trotzdem passt

- Sie veröffentlichen **täglich** Inhalte und wollen alles selbst pflegen.
- Sie brauchen ein sehr spezielles Plugin-Ökosystem.
